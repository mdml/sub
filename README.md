# `sub`

Give the coding agent you already use subagents from any supported coding harness, with one durable place to observe the delegated work and retrieve its result.

`sub` is in pre-beta. There is nothing to install yet.

## Status

Current phase: scaffolding the repository and running the Agent Client Protocol boundary spike (`docs/spikes/acp-boundary.md`, once it exists). See [`CHANGELOG.md`](CHANGELOG.md).

## Layout

The repository layout is decided by the agents that build it and documented here as it lands. Until then, the only files are this README, the license, the changelog, and the agent instructions in [`AGENTS.md`](AGENTS.md).
